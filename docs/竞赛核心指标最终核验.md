- 本地成功率、规则准确率、authoritative-final rate 均为 100%。
- Qwen 选择 60/180，完成 60/60，规则一致率 100%。
- score-input -> provisional 平均 163.330968 ms。
- 该报告明确记录 `perception_model_executed=false`：仓库没有可运行的工业视觉权重和带标注视觉测试集，
  因此不能将 163.331 ms 表述为“原始图像 -> 决策”的完整视觉 E2E。
- selected-only Qwen 平均 207.875570 ms，不是 180 个事件的总体 E2E；总体摊销 Qwen 延迟为 69.291857 ms。

## 弱网与并发复核

当前静态 Q5 使用真实故障代理完成完整工业矩阵并生成冻结报告：

- mild 40/40、severe 40/40：本地成功率和准确率均 100%，authoritative-final rate 100%。

- concurrency 1/2/4/8 各 40 个事件：本地成功率、准确率、authoritative-final rate 均 100%，无连接重置。
- concurrency 4/8 时，单 slot 模型在 0.5 s 限时内的 Qwen 完成率分别为 42.8571% / 28.5714%；
  其余请求按确定性规则安全回退，因此业务保持率仍为 100%，但不能表述为高并发下 Qwen 全部完成。

根因修复为在 HTTP server 构造前设置 backlog=128；此前在 `listen()` 后赋值没有改变内核监听队列。

## 提交材料表述边界

1. 内存写“静态 Q5 进程严格观测峰值 1.047 GB”，不要写模型文件大小等同运行内存。
2. 工业写“受控 RGB/红外 score 事件 -> 决策”，不要写成已实测原始图像视觉网络。
3. 时延主表同时列事件均值和更严格的窗口均值；不要只列较好的一项。
4. 跨机时延在 Nano 时钟修复前全部排除，只使用同机单调时钟口径。
5. 通用能力、代码能力和同协议 TTFT 暂列缺口，不引用旧候选或异协议数字冒充通过。
6. 并发 8 已不再发生连接重置；但单 slot Qwen 在并发 4/8 会触发部分超时并走安全回退，演示时应如实区分“业务成功”与“Qwen 完成”。
