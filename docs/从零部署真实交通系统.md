# 从零部署真实交通系统

本文只假设三台机器能够访问 GitHub。操作者不需要了解项目内部代码，但需要知道
三台机器的局域网地址：

- 一台云服务器；
- 两台 Jetson Orin Nano；
- 两台 Jetson 与云服务器网络互通。

正常路径使用云端 ExtraTrees，不要求安装云端 9B。Qwen3.5 9B 只用于异步异常
复核，需要时再安装。

## 一、三台机器拉取同一版本

三台机器都执行：

```bash
git clone https://github.com/scw1211/cloud-edge-scene-sdk.git
cd cloud-edge-scene-sdk
git checkout v0.13.1
```

如果尚未发布正式标签，使用：

```bash
git checkout main
```

## 二、安装云服务器

```bash
bash scripts/bootstrap_traffic_node.sh cloud
```

启动云服务：

```bash
.venv-cloud/bin/python scenes/freeway_traffic/deploy_node.py run --role cloud
```

另开终端检查：

```bash
curl http://127.0.0.1:18100/ready
```

返回`"ready": true`才继续。

如需启用云端9B，在已经安装 Ollama 的服务器上执行：

```bash
WITH_CLOUD_QWEN9B=1 bash scripts/bootstrap_traffic_node.sh cloud
.venv-cloud/bin/python scenes/freeway_traffic/deploy_node.py run \
  --role cloud \
  --with-cloud-qwen9b
```

9B不计入常态200毫秒路径。

## 三、安装两台 Jetson

Jetson必须先具备与本机 JetPack 对应的 NVIDIA PyTorch。安装脚本会检查
`torch.cuda.is_available()`，不满足时立即停止，不会静默退回CPU。

两台Jetson分别执行：

```bash
bash scripts/bootstrap_traffic_node.sh edge
```

脚本会完成：

1. 创建独立 Python 环境；
2. 安装公共 SDK 和真实交通插件；
3. 编译固定版本的 CUDA `llama-server`；
4. 下载 Edge-Qwen 与 PEMS08 推理数组；
5. 核对全部模型的字节数和 SHA-256；
6. 建立并验证 Edge-Qwen 活动发布。

若系统没有虚拟环境模块、CMake或编译器，先安装系统包：

```bash
sudo apt update
sudo apt install -y python3-venv git cmake build-essential
```

JetPack自带CUDA Toolkit，不要安装桌面版CUDA覆盖它。

## 四、启动两台边缘

把下面的`192.168.31.160`换成实际云服务器地址。两台Jetson均执行：

```bash
.venv-edge/bin/python scenes/freeway_traffic/deploy_node.py run \
  --role edge \
  --cloud-url http://192.168.31.160:18100 \
  --llama-binary runtime/bin/llama-server \
  --parallel 2 \
  --device cuda
```

分别检查：

```bash
curl http://127.0.0.1:18190/health
curl http://127.0.0.1:18101/ready
```

两个接口都成功才表示边缘节点就绪。

如需退出SSH后继续运行，安装为系统服务。云服务器执行：

```bash
bash scripts/install_traffic_systemd.sh cloud
```

两台Jetson分别执行：

```bash
CLOUD_URL=http://192.168.31.160:18100 \
  bash scripts/install_traffic_systemd.sh edge
```

系统服务安装需要当前用户具有`sudo`权限。

## 五、运行一个真实双边缘样本

三台机器先完成 NTP 同步。生成一个未来十秒的共同时间：

```bash
python -c 'import time; print(int((time.time()+10)*1000))'
```

记下输出值，并设置同一个实验编号。Jetson A：

```bash
.venv-edge/bin/python scenes/freeway_traffic/send_real_partitions.py \
  --edge-url http://127.0.0.1:18101 \
  --partitions 0,1 \
  --sample-id 0 \
  --experiment-id clean01 \
  --start-at-ms 共同时间 \
  --device cuda
```

Jetson B：

```bash
.venv-edge/bin/python scenes/freeway_traffic/send_real_partitions.py \
  --edge-url http://127.0.0.1:18101 \
  --partitions 2,3 \
  --sample-id 0 \
  --experiment-id clean01 \
  --start-at-ms 共同时间 \
  --device cuda
```

任意能访问三台机器的电脑执行：

```bash
python scenes/freeway_traffic/verify_real_two_edge.py \
  --edge-a http://JetsonA地址:18101 \
  --edge-b http://JetsonB地址:18101 \
  --cloud http://云服务器地址:18100 \
  --experiment-id clean01 \
  --sample-id 0
```

只有输出`"status": "passed"`、云端收到4/4成员、四个边缘复核状态全部完成且
残余冲突为0，才算整个系统部署成功。

## 六、常见问题

### 下载时报404

SDK v0.13.1 继续复用已经发布的`traffic-assets-v0.13.0`资产；代码版本与大资产
版本彼此独立。安装器不会用假文件代替模型，也不会跳过 SHA-256。

### Jetson提示Python版本不兼容

SDK支持Python 3.8及以上。JetPack 5的Python 3.8可以直接使用；不要为了更换
Python而破坏NVIDIA PyTorch。

### 边缘模型服务启动后退出

使用本文的`deploy_node.py run --role edge`统一管理模型和边缘服务，不要通过
短生命周期SSH命令单独启动子进程。

### 单组超过200毫秒

分别查看Student/本地规则路径和Edge-Qwen路径。Edge-Qwen只处理少量不确定
事件；不能通过删除慢样本、修改路由阈值或缩短汇聚窗口伪造达标结果。
